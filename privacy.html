Privacy Policy

Last updated: November 6, 2026

Kajurema Postagem ("the tool") is a private desktop tool used only by the owner of the YouTube channels Kajurema and Por Dentro das Coisas to upload and schedule the channels' own videos. This policy explains what data the tool uses and how.

YouTube API Services

The tool uses YouTube API Services (YouTube Data API v3). By using the tool you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

Information the tool accesses

  • Google OAuth authorization (access and refresh tokens) for the YouTube scopes the owner grants, used only to act on the owner's own channels.
  • Basic channel information (channel ID and channel title), read to confirm that the signed-in account is the expected channel (Kajurema or Por Dentro das Coisas) before any upload.
  • Playlist names of the same channel, read only to find or create the playlist the owner chose.
  • Upload records: the ID, link and scheduled time of each video the tool uploaded, so the same video is never uploaded twice.

The tool does not access comments, subscribers, analytics, messages, or any data from other YouTube users or channels.

How the information is used

Only to upload the owner's approved videos to the owner's own channels and to set their title, description, tags, schedule, thumbnail, captions and playlist. The data is not used for advertising, profiling, analytics or any other purpose.

Storage

All of this data is stored only on the owner's own computer, in local files of the tool. There is no server, no database in the cloud, and no copy kept by anyone else. The data stays there only while the owner keeps the tool authorized; it is deleted when the owner revokes access or deletes the tool's files.

Sharing

The tool does not sell, share or transfer any user data to third parties. Data is sent only to Google/YouTube, through the YouTube API, to perform the uploads the owner requested.

Cookies, ads and third-party content

The tool does not use cookies, does not show ads, and does not allow third parties to serve content or ads or to collect information. This website has no cookies, ads or tracking scripts. It is hosted on GitHub Pages, and GitHub may log technical data such as IP addresses as described in the GitHub Privacy Statement.

How to revoke access

You can revoke the tool's access to your Google account at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After revoking, the tool can no longer access YouTube, and its stored authorization stops working. To delete stored data, delete the tool's local files, or ask us at the contact below.

Changes

If this policy changes, the new version will be published on this page with a new date.
